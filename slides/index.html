01 / 基礎概念入門

什麼是「熱門歌曲科學（Hit Song Science）」？

在音樂資訊檢索（MIR）領域，科學家試圖回答：「我們能不能在歌曲發行前，就透過聲音訊號預測它會不會進榜？」

核心假設：聲學群聚理論

  • 人類大眾在特定時期的聽覺審美並非完全隨機。
  • 熱門歌曲在速度（BPM）、響度、節拍穩定度等量化指標上，往往會聚集在特定的「甜蜜點區間」。
  • 機器學習模型（如 Random Forest）分類「是否進榜」準確率可達 85%–88%。

純音訊模型的天花板

  • 當研究人員嘗試僅用音訊特徵去預測「精確串流熱度（0–100分）」時，回歸解釋力 R² 僅約 20.2%（AUC 0.74）。
  • 關鍵啟示：好聽的音訊參數只是「入場券」；要解釋 K-Pop 的病毒式爆紅，還必須看曲風結構、短影音演算法與編舞視覺。

02 / 量化聽覺指紋

資料科學家如何把「音樂」變成數字？

Spotify Web API 透過訊號處理，將一首歌拆解為五個核心量化特徵（0.0 至 1.0）：

三大正相關推進器

  • Danceability（可舞性）：節拍穩定度與律動規律性。全球熱門 K-Pop 平均高達 0.76。
  • Energy（能量值）：感知強度、動態密度與速度感。舞曲主打通常落於 0.75–0.85。
  • Loudness（響度, dB）：現代流行樂普遍將母帶響度推高至 -6 dB 至 -4 dB，在手機喇叭上更具衝擊力。

兩大風格分水嶺指標

  • Valence（情緒正向度）：高分代表快樂明朗（大調）；低分代表暗黑酷帥（小調）。
  • Acousticness（原聲程度）：與全球串流熱度呈負相關——現代主流 K-Pop 高度依賴電子合成器與數位重低音。

03 / K-Pop 的結構魔法

打破歐美公式：多段式拼接與 Anti-Drop

傳統歐美流行樂由單一主旋律線性推進；K-Pop 則像「高密度感官蒙太奇」，平均每 15–20 秒 切換一次曲風與音色。

1. 多段式拼接 (Patchwork)

在一首 3 分鐘歌曲中無縫融合 3 至 5 種曲風（如 Trap 主歌 → R&B 導歌 → EDM 副歌），持續刷新聽覺多巴胺，防止聽眾滑走。

2. 反高潮 (Anti-Drop)

在 Pre-Chorus 將音量與頻率堆疊到頂點後，副歌瞬間抽空所有鼓組，只留重低音與氣音人聲（如 aespa、NewJeans），用「留白反差」製造記憶點。

3. 雙語音節 Hook

副歌大量安插開放母音的簡短英文詞（如 Super Shy, Next Level）與擬聲詞，讓非韓語母語者聽一遍就能跟著哼唱。

雙市場聽覺畫像解讀

  • 韓國本土 Melon（大眾日常聆聽）：偏好高 Valence、清亮旋律、大調與樂團/抒情原聲感（Easy-Listening），適合通勤與日常循環。
  • 全球 Spotify（派對與舞台視覺）：將 K-Pop 視為高強度舞曲，偏好小調暗黑感（低 Valence）、重低音與高能量群舞曲風。

06 / 多模態 AI 預測模型

為什麼只聽聲音不夠？多模態模型的三大支柱

K-Pop 是高度整合的「視聽產業」。結合 音訊 + 歌詞 + 編舞動作 後，爆紅預測 AUC 從 0.74 躍升至 0.91：

1. 音訊頻譜 (Audio)

使用 CNN 分析梅爾頻譜圖（Mel-Spectrogram），提取「副歌與主歌的能量對比度」，捕捉 Anti-Drop 或 Beat Drop 的戲劇反差。

2. 雙語歌詞 (Lyrics)

計算歌詞重複壓縮率與英文佔比（熱門曲平均達 38%–45%）。高英文比例能顯著降低全球聽眾的跟唱與記憶門檻。

3. 編舞視覺 (Choreography)

透過姿態估計模型分析副歌 15 秒舞蹈：上半身手勢集中、適合直式手機螢幕拍攝的 Point Dance，其挑戰參與度是複雜走位舞的 3.4 倍。

08 / 方法論：LLM Wiki 知識庫工程

這份簡報是如何從 LLM Wiki 編譯出來的？

不同於傳統 RAG 每次提問才臨時搜尋文件碎片，LLM Wiki 將 5 篇論文預先編譯為互相關聯的持久化知識網絡：

Layer 1: Raw Sources

5 篇 MIR 論文存放於 raw/，保持唯讀不可變，確保所有數據（如 2:38、AUC 0.91）皆有明確學術出處。

Layer 2: Compiled Wiki

AI 透過 AGENTS.md 規範，將論文拆解為 Sources / Concepts / Entities 雙向連結頁，並標註跨論文矛盾（如 Melon vs. Spotify）。

Layer 3: Verification & Slides

生成簡報時先讀取 index.md 與 overview.md，再經過「事實核對閘門」確認無數據幻覺後才輸出 HTML。

09 / 總結與核心帶走觀念

K-Pop 爆紅公式的四大關鍵結論

1. 聲學是基礎，結構是靈魂

高 Energy 與 Danceability 決定商業門檻，但每 15–20 秒切換音色的「多段式拼接」與 Anti-Drop 才是留住聽眾的關鍵。

2. 時間軸全面向演算法妥協

歌長壓縮至 2 分半左右、前奏縮至 4 秒、刪減 Bridge，一切設計皆為了「前 3 秒留存」與「30 秒串流循環」。

3. 國內外市場是兩套聲學標準

韓國 Melon 偏愛高 Valence 清新旋律；全球 Spotify 偏愛高 Energy 重拍舞曲，製作策略需依目標市場調整。

4. 視聽多模態決定最終天花板

音訊 + 40% 左右英文歌詞 + 上半身手勢編舞，能讓爆紅預測準確度（AUC）從 0.74 躍升至 0.91。
