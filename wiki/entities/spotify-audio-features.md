# Entity: Spotify MIR 五大核心音訊特徵

在 [[concepts/hit-song-science]] 與 [[concepts/cross-cultural-preference]] 中，研究人員最常透過 Spotify Web API 提取以下五項量化指標來描繪一首歌的聽覺指紋：

1. **Danceability（可舞性, 0.0–1.0）**：衡量節奏穩定度、重拍強度與律動規律性。K-Pop 全球熱門曲平均達 **0.76**。
2. **Energy（能量值, 0.0–1.0）**：衡量感知響度、動態範圍與音色密度。全球榜單偏好 **0.79** 左右的高能量曲目。
3. **Valence（情緒正向度, 0.0–1.0）**：衡量音樂傳達的快樂/積極程度。韓國本土 Melon 偏好 **0.62**（明快正向），全球 Spotify 偏好 **0.46**（偏酷帥/小調）。
4. **Acousticness（原聲程度, 0.0–1.0）**：衡量非電子合成原聲樂器的佔比。主流 K-Pop 舞曲通常低於 0.15，但韓國本土熱門曲平均達 **0.28**。
5. **Loudness（整體響度, dB）**：以分貝計算的整體音量，現代熱門歌曲普遍壓縮在 **-6 dB 至 -4 dB** 之間以增強聽覺衝擊力。
